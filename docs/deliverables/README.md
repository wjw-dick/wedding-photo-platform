# 交付文档说明

本目录存放 T119–T122 四份 Word 交付物，均按统一排版基线生成：A4、上下左右 2.5cm、黑体标题、宋体 12pt 正文、浅灰表头、页脚页码、无 emoji、封面四要素、修订记录。

| 文件 | 对应任务 | 说明 |
|---|---|---|
| `T119-需求规格说明书.docx` | T119 | 七章：概述、业务流程、功能需求、编码规则、界面、核心表结构、非功能需求；校验类需求含通过/失败双分支 |
| `T120-技术方案与开发报价.docx` | T120 | 八章：概述、技术架构、技术选型、工作量、报价、实施计划、风险、结论；232 人天，建议单价 1900 元/人天，合同价 440,800 元 |
| `T121-用户使用手册.docx` | T121 | 角色权限矩阵、平台端、租户后台、官网与会员端、生产/供应商/渠道端、公众号、异常处理、FAQ、附录 |
| `T122-三份文档一致性自检报告.docx` | T122 | 端名、角色名、模块名、技术栈版本、人天报价复算、实施周期六项核对，以及 Word 排版基线核查 |

## 重新生成

```bash
python3 docs/deliverables/gen_t119.py
python3 docs/deliverables/gen_t120.py
python3 docs/deliverables/gen_t121.py
python3 docs/deliverables/gen_t122.py
```

`gen_t122.py` 会读取前三份 Word，逐项校验端名、角色名、模块名、技术栈版本、报价计算式、实施周期与排版结构；若输出 `missing: {}` 且三份文档排版行均为“A4 / 2.5cm / 宋体 12pt / 黑体 / 有 / 有 / 无”，表示自检通过。

## 说明

1. 目录使用 Word 域。首次打开若目录未显示页码，右键目录区域选择“更新域”，勾选“更新整个目录”。
2. 文档中的金额、人天、周期在三份文档与自检报告之间已统一；修改任一数值后必须重新运行 `gen_t122.py`。
3. 外部微信、支付、短信、云存储凭证与 App 上架材料不属于文档一致性问题，按 `checklist.md` 与 `docs/test/regression-report.md` 单独跟踪。
