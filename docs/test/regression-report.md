## 三、首轮缺陷与修复

首轮执行结果为 17/23，通过率 73.9%。定位到 5 类问题，修复后复测全部通过。

| 编号 | 现象 | 根因 | 修复 |
|---|---|---|---|
| BUG-01 | 跨租户访问订单详情返回 500 | `queryForMap` 按租户过滤后无记录，抛出 `EmptyResultDataAccessException` | 新增 `TenantDataGuard`：先按租户查，存在但属其他租户返回 403，彻底不存在返回 404；订单详情、状态流转、会员详情接入 |
| BUG-02 | 跨租户访问会员详情返回 500 | 同上 | 同上，会员详情接入归属校验 |
| BUG-03 | 合同 PDF 生成返回 500 | 控制器强制解析 `templateId`，未传时得到字符串 `null`；新租户也无默认模板 | 新增 V4 迁移为历史租户补默认模板；开通流程写入默认模板；未传 `templateId` 时自动取租户首个模板，仍无则使用内置模板 |
| BUG-04 | `.jpg` 伪装可执行文件上传成功 | 仅信任扩展名与 `Content-Type`，未校验文件头 | 新增 `FileTypeValidator`，按扩展名校验魔数；图片、视频、音频、PDF、Office 白名单；单文件、分片合并、公众号素材三处接入 |
| BUG-05 | 不存在的接口返回 500 | `NoResourceFoundException` 落入兜底异常处理 | 全局异常处理新增 404、413、415 映射；未知接口返回 404，超限返回 413，类型不符返回 415 |
| BUG-06 | 支付幂等用例误报 | 脚本用字符串比较 `100.0` 与 `100.00` | 改为数值比较，并增加支付记录条数断言；业务代码无需修改 |

## 四、覆盖范围说明

本轮为接口级自动化回归，已覆盖：平台与租户双入口鉴权、租户开通、通用 CRUD、订单创建、支付幂等、档期并发唯一性、报表异步任务、合同 PDF、二维码、上传类型白名单、SQL 注入、UnionID 会员合并、审计只读、平台端数据边界。

未纳入自动化、需外部凭证或人工验收的部分：

1. 微信真实凭证、模板消息到达、公众号菜单发布、素材与草稿发表。
2. 微信支付、支付宝真实扣款与退款回调；当前以线下收款与模拟回调验证幂等。
3. 短信真实发送；未启用渠道时按设计降级写日志。
4. 对象存储 S3/OSS/COS/MinIO 真实连通性；本地驱动已实测，其余驱动已完成代码与配置表单，待凭证联调。
5. Flutter App 打包与真机安装；当前环境无 Flutter SDK。
6. 2000 张客片批量上传压测、100 并发档期压测；本轮完成 20 并发唯一性验证。
