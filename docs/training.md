# 婚礼影像多端 SaaS 平台培训材料

- 版本：V1.0
- 适用对象：平台运营人员、租户管理员、门店店长、门市、财务、摄影师、化妆师、修片师、供应商、渠道商
- 培训方式：管理员集中培训 1 场；门店与一线角色分角色培训各 1 场
- 配套材料：《需求规格说明书》《技术方案与开发报价》《用户使用手册》《上线检查表》

## 一、系统全景

平台由“一后端多前端壳”组成，共 9 个可登录端：

| 序号 | 端名 | 入口 | 主要使用者 |
|---|---|---|---|
| 1 | 平台运营端 | `/platform/*` | 平台超管、平台运营、平台财务 |
| 2 | PC 品牌官网 | 官网域名 | 访客、会员 |
| 3 | PC 租户后台 | `/tenant/*` | 租户管理员、店长、门市、财务、运营、客服、仓管 |
| 4 | 微信公众号（服务号） | 微信内 | 粉丝、会员 |
| 5 | 小程序·用户端 | 微信小程序 | 会员、客户 |
| 6 | H5 分享页 | 微信内或浏览器 | 访客、会员 |
| 7 | 小程序·生产端 | 微信小程序 | 摄影师、化妆师、修片师 |
| 8 | 小程序·供应商端 | 微信小程序 | 相册、相框、礼服、花艺供应商 |
| 9 | 小程序·渠道商端 | 微信小程序 | 酒店、婚庆策划、礼服馆等渠道商 |
| 10 | App·会员端 | iOS / Android | 会员、客户 |

> 说明：平台覆盖 10 个端形态。H5 分享页复用官网与会员会话，不单独计入登录端，因此登录端为 9 个；App 为 Flutter 会员端。门店店员不单列端，日常作业在租户后台完成。

| 租户开通、停用、续期、删除 | 可操作 | 可操作 | 只读 |
| 套餐与配额 | 可操作 | 可操作 | 只读 |
| 账单与收款标记 | 可操作 | 只读 | 可操作 |
| 公告 | 可操作 | 可操作 | 不可见 |
| 平台账号管理 | 可操作 | 不可见 | 不可见 |

|---|---|---|
| 小程序·生产端 | 员工账号 + 密码，首次绑定微信后免密 | 员工必须归属门店与角色 |

| 小程序·用户端 / H5 / App | 微信授权或手机号 | 以 UnionID 合并为同一会员 |

## 三、平台运营端培训

### 3.1 登录与看板

1. 打开平台端登录页，输入平台账号与密码。
2. 进入看板，查看租户总数、试用数、到期数、欠费数、本月收入与套餐分布。
3. 看板只展示汇总，不提供任何租户订单、会员、客片明细入口。

### 3.2 开通租户

1. 进入“租户管理”，点击“开通租户”。
2. 填写租户编码、名称、行业、联系人、联系电话，选择套餐与试用标记。
3. 设置主管理员用户名与初始密码。初始密码仅本次展示。
4. 提交后系统自动生成默认角色、菜单、参数、门店、默认套系、档期资源、消息通道与合同模板。
5. 将租户编码、管理员账号、初始密码交付客户，要求首次登录后修改密码。

验收口径：从提交到租户管理员可登录不超过 3 分钟。

### 3.3 租户生命周期

| 操作 | 路径 | 注意事项 |
|---|---|---|
| 停用 | 租户详情 → 状态 | 停用后登录被拒、接口 403，数据保留可导出 |
| 续期 | 租户详情 → 续期 | 填写新的到期日，操作入审计 |
| 配额调整 | 租户详情 → 配额 | 席位、公众号数、存储、短信、API 调用量五类分别设置 |
| 删除 | 租户详情 → 删除 | 二次确认，业务数据归档，平台留痕，不影响其他租户 |
| 导出 | 租户列表 → 导出 | 平台导出需二次确认并记录审计 |

### 3.4 套餐、账单、公告、审计

1. 套餐：新增或编辑套餐名称、价格、席位、存储、公众号数、短信条数、API 调用量，保存后新开通租户按新套餐执行。
2. 账单：按月生成，核对席位数与单价，确认无误后标记已付；逾期账单在列表中高亮。
3. 公告：填写标题、正文、生效时间与目标租户，发布后可查看已读统计。
4. 审计：按时间、操作人、模块筛选；只读，不可删除。

## 四、租户后台培训

### 4.1 首次登录与基础配置

1. 使用租户编码、管理员账号、初始密码登录。
2. 进入“系统配置 → 参数”，核对门店名称、客服电话、营业时间、ICP 备案、定金比例、尾款节点、加片单价、客片保留期、水印文案。
3. 进入“门店与影棚”，维护门店地址、电话、容量与影棚状态。
4. 进入“角色权限”，为店长、门市、摄影师、修片师、财务分配菜单与数据范围。
5. 进入“存储配置”，选择本地、S3、OSS、COS 或 MinIO，填写参数并做连接测试；密钥保存后仅显示掩码，留空表示不修改。
6. 进入“消息配置”，按需启用站内信、公众号模板消息、小程序订阅消息、App 推送与短信渠道。

### 4.2 套系与商品

1. 新增套系，填写套系编号、名称、价格、定金、拍摄时长、服装套数、场景数、精修张数、交付天数。
2. 富文本编辑套系详情，图片组件支持拖拽排序、批量删除与放大预览。
3. 配置加购项：加片、加册、换框、加急、礼服升级，填写单价与计价单位。
4. 上架前核对合规展示项：包含项目、拍摄时长、服装套数、成片张数、交付周期、加购单价。

### 4.3 档期与预约

1. 进入“档期日历”，切换日、周、月视图，查看摄影师、化妆师、影棚、跟拍机位占用。
2. 新建预约时选择门店、套系、日期时段与指定资源。
3. 系统在服务端校验同一资源同一时间窗唯一性，冲突时返回明确提示。
4. 锁档默认 30 分钟，未付定金自动释放；付定金后锁档转为正式占用。
5. 拖拽改派需二次确认，改派后原资源自动释放。

### 4.4 订单与收款

订单状态：留资 → 到店 → 定金 → 排期 → 拍摄 → 选片 → 精修 → 制作 → 取件/交付 → 完成。异常态包括改期、退定、加购、返工、超期。

1. 新建订单：选择客户、套系、拍摄日期、资源、来源渠道，系统生成订单号与套系快照。
2. 收款：定金、尾款、加购分别登记；重复支付回调按 `payNo` 幂等，只记一次账。
3. 改期：填写新日期、新时段、新资源与原因，系统校验新档期并释放原档期。
4. 取消：填写原因，选择是否退定金，退款操作入审计。
5. 合同：选择模板生成合同 PDF，中文可正常显示；签署记录可在订单详情查看。
6. 发票：录入抬头类型、抬头、税号、金额，开具后回填发票号。

### 4.5 拍摄生产

1. 派工：为订单分配摄影师、化妆师、影棚与集合时间地点。
2. 生产端查看今日任务、客户偏好、拍摄清单与导航。
3. 现场打卡：读取 GPS，超出配置半径拒绝打卡；打卡照片可回看。
4. 原片上传：支持分片、断点续传、进度回传与 MD5 秒传；上传完成生成对账记录。
5. 拍摄完成后订单自动进入选片状态。

### 4.6 选片、修片、制作、交付

1. 选片：生成选片单，设置限时；客户逐张选入，加片实时计价；确认单签字后金额回写订单。
2. 修片：派发修片任务，修片师领取、提交、返工；返工次数受上限约束，超时预警。
3. 制作：按套系规格自动生成相册、相框、摆台、海报制作单；可派发给供应商，回传进度、发货、到店验收。
4. 交付：生成交付通知，支持站内信、公众号模板消息、小程序订阅消息、App 推送；客片保留期默认 90 天，到期前提醒，可延期一次。
5. 礼服：建档、租出、归还、清洗、赔偿、超期计费；礼服档期与订单档期联动。

### 4.7 会员、渠道、供应商、员工

1. 会员：维护等级、积分、储值、卡券；积分与储值调整必须填写原因并留痕。
2. CRM：线索登记、跟进、转门店、保护期与超时提醒。
3. 渠道：渠道商建档、报单归属、首报保护期、佣金比例与阶梯、结算单。
4. 供应商：档案、资质、制作单、进度、发货、月度对账、资质到期提醒。
5. 员工：排班、计件规则、提成明细、结算单；规则变更留痕，历史订单按成交时快照计算。

### 4.8 报表与导出

1. 进入“统计报表”，选择报表类型与时间范围。
2. 9 类报表指标口径与订单数据一致。
3. 数据量大时使用异步导出，任务完成后下载 CSV；下载地址为带令牌的临时地址。

### 4.9 菜单可视化

1. 选择端：PC 后台、PC 官网、公众号、小程序 tabBar、H5 底部。
2. 三栏拖拽调整层级与排序，编辑标题、图标、类型、路径、可见性。
3. 实时预览与保存结果一致；保存后即时生效，无需发版。
4. 公众号菜单需在“公众号管理 → 菜单管理”执行“预览到微信 → 发布”。

### 4.10 审计

审计日志覆盖订单修改、派工、凭证修改、菜单发布、导出、退款等操作。租户端只读，可按时间、操作人、模块、门店筛选并导出。

## 五、业务端培训

### 5.1 PC 品牌官网

1. 访客可浏览首页、套系中心、套系详情、客片案例、旅拍线路、门店分布、品牌故事、资讯、联系我们、资质公示。
2. 客片案例仅展示已授权内容；撤回授权后自动下架。
3. 留资表单含防重复提交与验证码，提交后进入 CRM 并分配门店。
4. 中英切换即时生效，未翻译字段回落中文并标注。
5. SEO 标题、关键词、描述按语言配置；`sitemap.xml` 与 `robots.txt` 可访问。

### 5.2 微信公众号

1. 凭证：填写 AppID、AppSecret、Token、EncodingAESKey，保存后掩码显示；服务器 URL 自动生成并可复制。
2. 粉丝：关注自动入库，取关更新状态；支持昵称搜索、分页同步、标签写回。
3. 标签：新增、同步、删除；超限有提示。
4. 模板消息：从微信同步模板，发送与映射统一在消息配置，不产生第二套模板表。
5. 菜单：编辑、预览、发布；发布失败保留旧菜单。
6. 自动回复：关注回复、消息回复、关键词完全匹配、半匹配、兜底。
7. 素材：图片、语音、视频上传；视频带 thumb；超限被拦。
8. 草稿与发表：单图文、多图文、封面选择、预览、提交发表；发表记录保留失败原因。
9. 无正式凭证时，同步接口返回明确错误，不显示假成功。

### 5.3 小程序·用户端

1. 微信授权登录，与公众号、H5、App 合并为同一会员。
2. 浏览套系、筛选门店/风格/价格，查看合规展示项。
3. 预约：门店 → 套系 → 日期时段 → 指定摄影师/化妆师 → 留资 → 锁档 → 定金支付。
4. 并发抢档仅 1 单成功，失败方看到明确提示与推荐时段。
5. 订单中心查看状态、电子合同、改期与退定申请。
6. 在线选片、加片计价、确认单签字；精修逐张确认与返工申请。
7. 会员中心查看积分、储值、优惠券、客片保留期。
8. 婚礼当日直播相册在有效期内可访问，过期提示。

### 5.4 H5 分享页

1. 微信内直接打开套系、样片、案例分享落地页。
2. 活动报名与留资表单提交后进入 CRM。
3. 支付完成后回跳并同步订单状态。
4. 底部导航按菜单可视化配置渲染；分享参数携带渠道码与门店码。

### 5.5 小程序·生产端

1. 员工账号登录，首次绑定微信后免密进入。
2. 查看今日/本周任务、集合时间地点、客户偏好、拍摄清单与导航。
3. 现场打卡，GPS 超半径被拒。
4. 原片批量上传，弱网重试可续传，后台可查上传记录。
5. 修片工作台领取、提交、返工；返工超上限被拦。
6. 查看计件业绩与提成明细。

### 5.6 小程序·供应商端

1. 查看待接单、在制、已发货、待对账四类数据。
2. 接单或拒单，拒单必须填写原因。
3. 回传制作进度，后台制作单同步更新。
4. 发货填写物流公司与单号。
5. 查看月度对账单，确认或申诉均留记录。
6. 上传营业执照、印刷资质、质量承诺书，到期前提醒。

### 5.7 小程序·渠道商端

1. 查看本月报单、成交、佣金预估。
2. 提交报单，系统按首报保护期判定归属；冲突时明确提示。
3. 查看我的客户、佣金明细与结算单。
4. 查看渠道专属价与物料二维码。
5. 两级下级渠道可见且不越权。

### 5.8 App·会员端

1. 手机号或 UnionID 登录，与小程序会员一致。
2. 预约、定金支付、订单进度、电子合同。
3. 选片、加购、精修确认、客片下载。
4. 消息推送与推送开关。
5. 隐私政策与权限声明在首次启动时展示。

## 六、异常处理

| 场景 | 系统表现 | 处理步骤 |
|---|---|---|
| 跨租户访问 | HTTP 403，提示无权访问其他租户数据 | 确认账号租户编码；不要手工改 URL 中的资源 ID；安全审计留痕 |
| 平台与租户互登 | HTTP 403 | 平台账号只进平台端，租户账号只进租户后台 |
| 档期被抢占 | 返回失败提示与推荐时段 | 刷新日历，改选资源或时段；不要重复提交 |
| 锁档超时 | 30 分钟未付定金自动释放 | 重新锁档并尽快完成定金支付 |
| 支付重复回调 | 同一 `payNo` 只记一次账 | 在订单详情核对支付记录，无需人工冲正 |
| 上传类型不符 | HTTP 415，提示文件内容与扩展名不符 | 使用原始图片或视频文件，不要改后缀 |
| 文件超限 | HTTP 413 | 压缩文件或使用分片上传 |
| 微信无凭证 | 明确业务错误，不产生假数据 | 在公众号凭证页补齐 AppID/AppSecret 后重试 |
| 租户欠费 | 写操作 403，读与导出可用 | 平台端续期或调整套餐后恢复 |
| 对象存储不可达 | 上传失败并提示 | 检查 Endpoint、Bucket、AK/SK 与网络；连接测试通过后再切换 |
| 短信渠道未启用 | 验证码降级写日志，页面明示 | 启用任一短信渠道并配置签名与模板 |
| 报表导出失败 | 任务状态 FAILED，保留失败原因 | 缩小时间范围后重试；仍失败联系技术 |
| 合同 PDF 失败 | 返回业务错误 | 检查模板是否存在；可在合同模板页恢复默认模板 |
| 审计无写入口 | 仅列表、详情、导出 | 属于设计约束，不是缺陷 |

## 七、FAQ

**问：开通租户后为什么没有默认套系？**
答：开通流程会写入一个默认套系、一个加购项、两个档期资源和一个默认合同模板。若使用历史版本开通，执行 V4 数据库迁移后会补齐合同模板，套系可在“套系管理”手工新增。

**问：平台管理员能看到客户订单吗？**
答：不能。平台端只提供租户汇总、配额、账单与审计，访问租户订单接口返回 403 或 404。

**问：为什么两个账号同时抢同一摄影师，只有一个成功？**
答：档期唯一性由服务端强制校验，并使用 Redis 分布式锁与数据库唯一约束双保险。失败方会收到明确提示。

**问：客户改期后原档期会释放吗？**
答：会。改期成功后原锁档释放，新档期重新校验；如新档期冲突，改期整体失败，原档期保持不变。

**问：加片价格改了，历史订单会变吗？**
答：不会。下单时写入套系与加购价格快照，后续改价只影响新订单。

**问：客片下载链接能转发给别人吗？**
答：签名 URL 有效期不超过 30 分钟，过期失效；下载与批量导出均写审计。请勿将链接发到公开群。

**问：撤回肖像授权后多久下架？**
答：系统设计为撤回后 24 小时内自动下架；前台 CMS、案例库、公众号素材、小程序样片统一按授权状态过滤。

**问：公众号同步粉丝失败，提示无凭证？**
答：这是预期行为。未配置正式凭证时不伪造成功，补齐凭证后重试。

**问：为什么审计日志不能删除？**
答：审计为合规只读数据，任何角色都不提供删除入口，保留期不少于 180 天。

**问：报表数据与看板不一致？**
答：看板为实时汇总，报表按所选时间范围与订单状态口径统计。先核对时间范围与状态筛选，再联系技术核对口径。

**问：App 无法安装？**
答：当前交付包含 Flutter 源码，需要在具备 Flutter SDK 的环境执行 `flutter create --platforms=android,ios .` 生成平台目录后打包；上架还需软著、开发者账号与隐私合规材料。

**问：微信支付/短信/OSS 没有真实凭证能上线吗？**
答：不能直接放量。代码与本地模拟已验证，但真实扣款、消息到达、存储连通性必须在取得正式凭证后按上线检查表补测。
